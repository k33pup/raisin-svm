# SVM для двух сортов изюма

## Воспроизведено

На готовых признаках UCI полиномиальный SVM дал **83,44% accuracy** — 751 верное предсказание из 900. Оценку провёл на десяти фолдах. Масштабирование в каждом фолде считал по его тренировочной части.

Первый скрипт вывел 85,56% по последнему фолду. Число попало в допуск, но проверка по всем предсказаниям дала другой результат. Агент передал расхождение модели, и та исправила расчёт. Все 900 сохранённых предсказаний совпали с отдельным контрольным запуском. [Лог агента](agent.log) · [Вывод Python](train.log) · [Предсказания](predictions.csv)

## Не воспроизведено

У авторов **86,44%** — 778 из 900 по матрице ошибок. Наш результат ниже на 3 процентных пункта и не попал в заданный диапазон 84,44–88,44%. [Таблицы 5 и 6 статьи](../text_tasks/raisin-svm/paper.pdf#page=8)

В статье указаны ядро и число фолдов. Точные разбиения, параметры SVM и способ масштабирования признаков для SVM не описаны. Для повтора задал их заранее. По одному прогону причину разницы установить нельзя. [Рецепт](task.md)

## Не проверялось

Взял готовые признаки из UCI, поэтому съёмка изюма и обработка фотографий остались за рамками. LR, MLP и метрики кроме accuracy в задачу не входили.
