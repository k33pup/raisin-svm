# Классификация изюма

Воспроизвести эксперимент с SVM у Çınar, Köklü и Taşdemir (2020). Использовать готовые признаки из UCI. Источники в PDF — §2.3, §2.5, §3.3 и таблицы 5–6. Сравниваем accuracy.

Страницы PDF: 3, 4, 5, 6, 8

Условия нашего запуска зафиксированы заранее. Используем StratifiedKFold с shuffle=True и random_state=42. StandardScaler обучается внутри каждого фолда только на его train. Для полиномиального SVC берём C=1.0, degree=3, gamma="scale", coef0=0.0. Эти решения относятся к нашей реализации. По статье нужно отдельно установить, что именно указали авторы.

На выходе нужны метрика и по одному предсказанию для каждой строки отложенных данных. Съёмка и обработка изображений, LR и MLP вне задачи.
